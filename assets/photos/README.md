# Фото для сайта Grand Power Tyres

Просто **положи сюда файл с нужным именем** — он появится на сайте автоматически.
Нет файла → показывается аккуратная заглушка. Есть файл → показывается фото.
Ничего в коде трогать не нужно.

Формат: **.jpg** (именно такое расширение и имя, как в списке ниже).
Рекомендуемый размер: услуги/галерея ~1200×800px, витрина ~900×1200px.
